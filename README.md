# Team Project – Online Shopping System

## Project Description
This project demonstrates collaborative software development using Git and GitHub. It contains separate modules for user login, product catalogue management, and shopping cart operations.

## Project Modules

### 1. Login Module
- Validates username and password.
- Checks user credentials.
- Displays successful or invalid login messages.

### 2. Product Catalogue Module
- Displays available products.
- Shows product names and prices.
- Uses product IDs to identify products.

### 3. Shopping Cart Module
- Allows products to be added to the cart.
- Displays selected products.
- Calculates the total price.

## Branches Used
- `main` – Main project branch.
- `feature-login` – Login module development.
- `feature-catalog` – Product catalogue development.
- `feature-cart` – Shopping cart development.
- `docs-readme` – Project documentation.

## GitHub Workflow
1. Create a GitHub repository.
2. Clone the repository to the local system.
3. Create separate branches for each module.
4. Develop and commit module files.
5. Push branches to GitHub.
6. Create Pull Requests to merge module branches.
7. Review changes using the Files changed tab.
8. Resolve README merge conflicts.
9. Merge approved changes into the main branch.

## Files in the Repository
- `login.py` – User authentication.
- `catalog.py` – Product catalogue.
- `cart.py` – Shopping cart operations.
- `README.md` – Project documentation.
